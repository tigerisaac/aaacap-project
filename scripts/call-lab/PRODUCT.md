# Local call lab

This operator tool lets Shield's owner exercise call-control behavior for a 25-user paid pilot without placing calls. The current deliverable is a local rehearsal and browser-routing preview. Real audio and live provider integration remain a separate approved phase.

The owner requested an automated test setup, a capped-run cost estimate, and a way to pass a simulated called recipient from the browser. They require approval before number purchases or real calls; production and the concurrently edited application must remain untouched.

## Surface contract

THESIS: Make the next local test and its evidence boundary immediately obvious.
OWN-WORLD: Shield's restrained green palette, native system typography, plain form controls, pale green-white field. This is an Operate surface, not marketing.
STORY: Choose fictional recipient and scenario; rehearse; inspect result; distinguish that result from a proposed paid run.
FIRST VIEWPORT: Local-only status, recipient/scenario controls and estimate. Signature interaction is the signed-routing preview, showing how recipient identity would travel without exposing its token. Motion is limited to short button color feedback and respects reduced motion.
FORM: Existing-product utility extension; code-led form and results list. No visual rebrand, generated comp or concept lottery. The narrow task and existing product language determine the composition.

## Required states

Unavailable server, ready, running, success, failure, routing preview. All data is synthetic. No live-call switch, credential input, microphone request or paid action. Two-column desktop layout becomes a single mobile column. Keyboard focus and status announcements must remain visible.
